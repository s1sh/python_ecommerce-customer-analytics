===============================================================================
HOW TO CONVERT JUPYTER NOTEBOOKS TO HTML (COMMAND-LINE)
===============================================================================
To generate/update the web-viewable HTML files in reports/html_notebooks/, 
run the following command in PowerShell / Command Prompt:

  jupyter nbconvert --to html notebooks/*.ipynb --output-dir=reports/html_notebooks/
